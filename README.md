# 📘 RutinasApp

**RutinasApp** es una aplicación web para gestionar rutinas de aprendizaje personalizadas. Permite a los usuarios registrarse, iniciar sesión, crear actividades semanales según sus intereses, y visualizarlas de forma organizada.

---

## Tecnologías utilizadas

- **Frontend:** Angular 17 (standalone) + Bootstrap 5
- **Backend:** Node.js + Express
- **Base de datos:** MySQL (con Sequelize ORM)
- **Autenticación:** JWT (JSON Web Token)
- **Interfaz gráfica:** HTML + CSS personalizado + Bootstrap
- **Herramientas:** Postman (para testear la API), Visual Studio Code
